# ParallelMinecraft
 
1. Download JDK 7u80 from: https://www.oracle.com/java/technologies/javase/javase7-archive-downloads.html
2. Download ANT v1.9.16 from: https://archive.apache.org/dist/ant/binaries/apache-ant-1.9.16-bin.zip
3. Set system variable JAVA_HOME to the installed folder jdk1.7.0_80
4. Set system variable ANT_HOME to folder apache-ant-1.9.16
5. Add  jdk1.7.0_80/bin to the system path
6. Add %ANT_HOME%\bin to the system path
7. In command prompt, navigate to the ParallelMinecraft folder, and run "ant clean jar" followed by "ant run"
